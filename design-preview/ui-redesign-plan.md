# 荒野中枢 · 前端界面统一方案

- 日期：2026-10-22
- 范围：`src/App.vue`、`src/pages/*`、`src/components/*`、`src/style.css` 的视觉与交互统一
- 预览：`design-preview/ui-redesign.html`（自包含静态页面，覆盖全部 12 个页面、主要弹窗和状态）
- 约束：本方案只产出分析与预览，不修改 `src/` 项目代码

## 1. 结论

当前页面已经共享同一套颜色 Token，但页面是并行开发的，导致统一视觉只停留在“颜色相同”这一层：

1. **外壳不统一**：主机切换器是一个表单 Select；导航在“主机层”和“实例层”整体替换；顶部只有纯文本面包屑；规范要求的全局底部操作栏没有实现。
2. **信息骨架不统一**：摘要、键值事实、表格、列表、空状态、错误提示分别有 3–4 套写法。发布页甚至自建了一套 CSS Grid 表格。
3. **操作层级不统一**：刷新有时是主按钮、有时是图标；一个页面最多出现 4 个平级按钮；创建备份在页面内完成，创建专服/主机却在弹窗；世界页有页面内 sticky 操作条，其他页面没有。
4. **状态表达不统一**：运行状态、任务状态、校验状态、连接状态的位置和样式各不相同；任务进度散落在列表、备份页和发布页；摘要里的状态计数下还附带对象名称或具体描述，数量多时无法逐一罗列；部分页面存在硬编码“未采集/未核实”或“暂不可用”。
5. **存在真实样式缺陷**：`BackupsPage.vue`、`ReleaseManagementPage.vue` 使用了未定义的 `var(--focus)`；全局 `textarea` 不在焦点环规则内；诊断页 `.diagnostic-grid` 没有定义；发布页固定列宽在 960px 下会溢出；主机列表把所有主机写成“未连接”。

统一方向不是换一套皮肤，而是把现有设计语言收口成一套可复用的**页面骨架 + 组件语法 + 操作规则**：继续使用现有颜色、圆角、字号和扁平风格，只统一层级、密度、位置和状态。

## 2. 设计基准

视觉基线以现有 `design-preview/world-config.html` 与 `src/style.css` 为准；本方案不引入新的品牌色、字体或视觉组件库，只统一层级、密度、位置与状态表达。

### 2.1 颜色与主题

沿用 `src/style.css` 的语义 Token，不改品牌色。预览额外补充了 `success-soft / warning-soft / danger-soft` 三个提示底色，用于错误块和危险确认，不用于装饰。

| 语义 | 亮色 | 暗色 | 用途 |
| --- | --- | --- | --- |
| canvas | `#f6f6f7` | `#151619` | 应用底色 |
| sidebar | `#efeff1` | `#191a1d` | 侧栏 |
| surface | `#ffffff` | `#1e1f22` | 主内容、弹窗、控件 |
| surface-muted | `#f1f1f3` | `#25262a` | 表头、只读面板、空状态 |
| surface-hover | `#e8e8eb` | `#2b2c31` | hover / 激活导航 |
| text / secondary / tertiary | `#202124` / `#676a70` / `#85878d` | `#f2f2f3` / `#a5a7ad` / `#858890` | 三级文字 |
| border / strong | `#dfe0e3` / `#c9cbd1` | `#303238` / `#44464e` | 分隔与控件边框 |
| accent / soft | `#5b63d3` / `#e9eafd` | `#8d93ee` / `#2a2c50` | 主操作、选中 |
| success / warning / danger | `#237a50` / `#99620a` / `#b93838` | `#61c992` / `#e1a346` / `#e36a6a` | 状态 |

暗色只覆盖语义值，页面不直接写原始色。焦点环统一为 `2px accent / offset 2px`，所有输入、按钮、可点击卡片、Tab 一致。

### 2.2 尺寸、字体与动效

| 项目 | 值 |
| --- | --- |
| 外壳 | 侧栏 236px；顶栏 56px；底部操作栏 60px；内容最大宽 1120px |
| 页面 | 内边距 24px（≤1100px 为 20/24px）；标题 20px；区块标题 16px；正文/控件 13–14px；元数据 11–12px |
| 控件 | 标准高 38px；紧凑按钮 32px；图标按钮 32px；输入圆角 6px；面板 8px；Dialog 10px |
| 栅格 | 4 / 8 / 12 / 16 / 24 / 32px；表单两列，最大宽 780px；区块间距 24–28px |
| 字体 | Inter → 系统中文字体；ID、路径、端口、日志用 JetBrains Mono / SFMono |
| 动效 | hover 120ms；弹层 160ms；Dialog 180ms；页面切换不加入场动画；只做 opacity / transform |
| 响应 | 最小 960×680；≤1100px 双栏转单栏并隐藏次要表格列；禁止整页横向滚动 |

### 2.3 图标

继续使用 `@lucide/vue`，统一描边 1.75px。导航与正文 16px，页面标题旁 18px，空状态 28px。图标按钮必须同时有 `aria-label` 与 tooltip；表格行内图标使用原生 `title`，避免被滚动容器裁切。

## 3. 信息架构

### 3.1 侧栏

保持“主机 → 专服”两层，但不再整体替换导航：

```
[品牌]
[当前主机上下文卡：上海服务器 / 已连接]
主机
  主机列表
  专服列表
  Release 管理
  主机环境
  连接设置
专服 · 生存一服
  专服概览
  世界
  MOD
  备份
  更新
  诊断
[应用设置]
[v0.2.0]
```

- 不再在左上角提供主机下拉切换：当前主机只作为**静态上下文卡**展示。切换主机统一回到“主机列表”完成，避免与列表页的“进入”动作冲突。
- 主机级与实例级导航同时存在；实例级分组标签带当前专服名与状态点，不在两层之间“跳变”。
- 侧栏中段独立滚动，底部“应用设置/版本”固定，保证 680px 高度下全部入口可达。
- 当前项使用 `surface-hover` 底色 + 600 字重 + accent 图标，并加 `aria-current="page"`。

### 3.2 顶栏与面包屑

- 面包屑分段可点击：`上海服务器 / 生存一服 / 世界配置`；主机名回专服列表，专服名回概览。
- 右侧只放**全局信息**：`演示数据` 小徽标、主题切换。SSH 状态、分片状态不重复常驻。
- 演示徽标从每个页面标题下移到顶栏，只出现一次。

### 3.3 底部操作栏

新增全局 60px 操作栏，承载三类信息，避免每页自造：

1. **空闲态**：连接/同步摘要（如“SSH 已连接 · 密钥认证 / 最近同步 10:42”）+ “任务记录”入口。
2. **任务态**：任务名、当前阶段、细进度条、“查看任务”；任务跨页面导航保持可见。
3. **长表单态**：仅世界配置使用，左侧“有未保存的更改 / 已保存，待应用 / 已应用”，右侧“预览应用 + 保存期望配置”。

列表页的新建、备份页的创建等**即时动作仍放在页头**；底部栏只承载“跨页任务”和“长表单提交”，避免重复主按钮。

## 4. 统一组件语法

### 4.1 页面骨架

```
页面标题（eyebrow + h1 + 状态）
摘要条（可选，最多 4 项；只展示聚合数值）
区块 1（标题 + 右侧元数据 + 内容）
区块 2 …
```

- `PageHeader`：左侧 eyebrow/title/status，右侧 actions。≤1100px 允许换行，操作右对齐。
- 页头最多一个主按钮；刷新统一为带图标的标准次按钮，不再用裸图标。
- 页面标题不再附带常驻流程说明；指纹、删除后果只在确认弹窗内出现。

### 4.2 摘要条 Summary

统一替代现有 `.summary-line`、`.identity-strip`、`.environment-summary` 的视觉部分：

- 上下 1px 边框，无卡片背景；2–4 项，等宽分栏。
- 每项只保留：12px 标签 → 20px 数值（状态类、数量类统一为“标签 + 数字”）。
- **状态计数不展示对象名称或具体描述**，不承担筛选、结果数或分页功能。例如“已停止 1”只说明有 1 个已停止专服，不在统计组件下列出“测试服”；具体对象只在下方表格中展示。
- 长列表由表格自身承载；本版不引入状态筛选、结果数工具条或分页，避免统计组件承担导航职责。
- 长 ID 使用 `.mono` + 省略 + `title`，不挤压操作列。

### 4.3 数据展示

| 场景 | 组件 | 规则 |
| --- | --- | --- |
| 同类对象比较 | 标准 table | 名称列带图标/副标题；状态列用 dot+文字；操作列右对齐；≤1100px 隐藏次要列，不横向溢出；长列表由页面滚动承载，不把对象名称塞回统计组件 |
| 少量键值 | facts (`dl`) | 左侧 12–13px 次要标签，右侧 13px 值；行间 1px 分隔；长值右对齐并允许换行 |
| 步骤/检查项 | list row | 36px 图标位 + 主副文案 + 右侧状态/操作；可展开项用 `details` |
| 对象预览/影响 | panel | 仅用于“创建预览、应用预览、备份快照”等临时信息，不把普通内容都装进卡片 |

发布页从自定义 Grid 表格改回标准 table；备份页移除页内分段控件，创建动作进入弹窗。

### 4.4 表单

- 每个字段使用可见 label；可选字段用 12px “可选” meta；示例只给短格式，不写流程说明。
- 两列表单最大 780px；描述/名单类字段占满整行；错误紧贴字段，错误文本 12px danger。
- 标准输入高 38px；`textarea` 与输入共用焦点环。
- 布尔值统一用 38×22 开关，不再混用原生 checkbox；只有“我已核对指纹”这类确认语义保留 checkbox。
- 联机凭据改为**状态行 + 替换按钮**，不在页面常驻两个密码输入框；替换在弹窗内完成，保存后不回显。

### 4.5 标签页与分段

- 一级分类：下划线 Tabs（基本设置/访问与联机/世界）。
- “世界”内部模式：Segmented（世界生成/世界规则），共用一套分片与分组控件。
- 分片：Segmented（Master/Caves）。
- 选项分组：圆角 Chip + 数量。
- 三种控件不再都做成“带边框按钮”，层级一眼可辨。
- Tab 使用 `role=tablist/tab/tabpanel`、`aria-selected`，支持左右方向键。

### 4.6 状态、提示与空状态

| 类型 | 规则 |
| --- | --- |
| 状态 | `dot + 文字`，success/warning/danger/muted 四档；不单靠颜色，文字必须存在 |
| 页面级阻断 | 页头下方 `alert danger`，含恢复步骤和设置入口 |
| 条件提醒 | `alert warning`，只在发生条件时显示 |
| 成功反馈 | 底部 toast，2.6s 自动消失；不插入布局流 |
| 空状态 | 44px 图标框 + 标题 + 一句说明 + 可选主操作；不用大插画 |
| 加载 | 表格用 3 行骨架，其他区块用一行 `正在读取…` + 轻脉冲；不改变布局高度 |

### 4.7 弹窗、菜单与 Toast

- Dialog 宽度分 440/560/680/860 四档；头部、body、footer 各自滚动/固定，长表单不把 footer 推走。
- 关闭按钮、Escape、点击遮罩、焦点返回触发器全部保留。
- 危险确认显示真实对象名与影响；删除专服/Release 需要输入名称/版本，按钮在匹配前禁用。
- 低频操作（删除）保留图标按钮 + tooltip；暂不引入第二套任务抽屉。
- Toast 固定在操作栏上方，右侧 24px，不遮挡主按钮。

| 备份 | 页内模式切换 + 预览 + 任务条堆叠；创建不是弹窗；图标无 aria-label | 状态摘要（仅计数）+ 标准表格；创建备份进入弹窗；恢复/删除确认；任务进入全局操作栏 |
| 更新 | 占位页；只有一个禁用主按钮和假 hero | 摘要（已安装/可用/ MOD 更新/最近检查）+ 范围 Segmented + 可用更新 panel + 历史表格；“创建备份并更新”弹窗预览 |

## 6. 交互与状态规则

### 6.1 操作层级

- 每页最多一个 accent 主按钮；危险动作使用 danger 描边或 danger 实心，只出现在确认弹窗的最终按钮。
- 刷新、检查、下载等只读动作统一为次按钮；不抢主操作。
- 长表单的提交固定在底部操作栏；即时动作（新建、创建备份、添加 MOD）留在页头。
- 同一对象的状态只在一个“权威位置”展示：页面级状态在页头，行级状态在表格；摘要只做聚合计数，不展示对象名称、不做筛选入口，具体对象始终在表格中查看。

### 6.2 任务反馈

- 所有跨页任务进入同一个底部操作栏：任务名 + 阶段 + 进度 + 查看任务。
- 任务详情弹窗显示阶段、时间线、错误码和恢复动作；关闭弹窗只关闭观察，不取消任务。
- 页面内不再保留第二套任务条；备份、发布构建、创建专服全部复用。

### 6.3 删除与高风险操作

- 删除专服：显示名称、目录、备份保留、运行影响，输入专服名确认。
- 删除 Release：显示版本、镜像摘要、实例/任务/容器引用，输入 DST build 确认。
- 删除连接：只移除本机记录，明确远端不受影响。
- 停止/重启：显示受影响分片与端口；重启单独确认，不顺带更新 DST/MOD。

### 6.4 响应式与可访问性

- 960×680：侧栏中段滚动；双栏转单栏；表格隐藏 `col-optional` 列；摘要两列；页头操作换行；长表格由页面滚动承载。
- 1480×920：内容最大 1120px 居中；表单/表格不拉伸到整屏。
- 亮/暗主题分别核对表头、hover、focus、disabled、空状态、日志和危险弹窗。
- 键盘：Tab 顺序、方向键切换 Tab、Escape 关闭弹层、焦点返回触发器、减少动效。

## 9. 预览使用说明

打开 `design-preview/ui-redesign.html` 即可，无需构建、无需服务。支持：

- 侧栏切换全部 12 个页面；面包屑与页头随之更新。
- 左上角只展示当前主机上下文，不再提供下拉切换；切换主机回到“主机列表”执行“进入/初始化”。
- 右上角切换亮/暗主题；应用设置中的主题选择同步。
- 世界页 Tab（基本设置/访问与联机/世界）/ 世界内部生成与规则 / 分片 / 分组切换；保存与预览应用更新底部栏和页头状态。
- 状态摘要只显示聚合数值，不在统计组件下罗列对象名称；具体对象在下方表格中查看，长列表随页面滚动。
- 备份创建、更新预览、发布运行验证、停止/重启、删除确认等弹窗。
- 创建专服两步流程、任务条模拟、删除确认、日志分片切换。
- 也可用 URL 参数直接打开：`?page=world&theme=dark`、`?page=backups&dialog=dialog-backup-create`。

> 预览中的主机、专服、备份、日志均为演示数据，顶部统一标记“演示数据”；不代表后端能力已实现。
