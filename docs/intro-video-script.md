# 《荒野中枢》介绍片 · 剪辑脚本

- 版本：v1 · 2026-11-07
- 成片：90 秒 / 16:9 / 1920×1080 / 30fps
- 形式：屏幕录制 + 动效字幕 + 音效设计，无真人出镜
- 产品：荒野中枢 1.0.5（Bate），Windows/macOS 桌面端，通过 SSH 管理 Linux 上的 DST Docker Compose 专服
- 交付：H.264 20 Mbps / AAC 320 kbps；另出 ProRes 422 母版、无字幕干净版、SRT
- 配套文件：[CSV 分镜表](intro-video-shotlist.csv) · [SRT 字幕](intro-video-subtitles.srt) · [可视化故事板](intro-video-storyboard.pptx)
- 说明：前半段终端报错为**情景演绎**，使用文档专用 IP、假主机名、假指纹与假 Token；不出现真实服务器信息、真实凭据和竞品标识

## 1. 一句话与情绪曲线

**一句话**：别再和命令行搏斗了——连上 Linux 主机，点几下，专服就开好了。

**情绪曲线**：

1. **共鸣**（0–27s）：深夜、终端、连环报错、越修越错，红框和抖动不断升级。
2. **停顿**（24–27s）：所有声音抽空，承认“问题不在你”。
3. **释放**（27–34s）：红框变成应用窗口的边框，颜色由红转绿，产品亮相。
4. **掌控**（34–75s）：连接、检查、创建、启动、配置，每一步都有明确结果。
5. **余味**（75–90s）：能力收束，品牌落版，“把折腾留给它，把游戏留给你们”。

**视觉基调**：前半段冷黑终端 + 高饱和红；后半段暖纸色应用 + 墨色文字 + 品牌绿。对比越干净，转场越有力。

## 3. 分镜详表

### 3.1 第一幕：痛点（00:00–00:30）

#### S01 · 提问（00:00–00:04）

- **镜头**：固定机位，全黑；左侧 1px 光标按 1 秒节奏闪烁；标题以打字机效果逐字出现，字距略宽；最后 4 帧缓慢推近 2%。
- **素材**：纯黑底 + 光标动画 + 字体排版；不需要实拍。
- **字幕**：第一行“为了开一个 DST 专服，”；第二行“你折腾了多久？”（第二行延迟 1.2s 出现，字重更粗）。
- **声音**：室内底噪、远处键盘声、单音钢琴；音乐低频脉冲在 00:02 进入。
- **转场**：在“久？”落下的一帧硬切到终端。

#### S02 · 连接（00:04–00:07）

- **镜头**：终端窗口全屏，四周留 40px 黑边；顶部标题栏做模糊处理；输入 `ssh root@203.0.113.24`，回车；出现 Ubuntu 登录横幅；光标停在新行。镜头 100%→104% 慢推。
- **素材**：V-TERM-01。终端配色：背景 `#0B0B0A`、正文 `#E8E4DA`、提示符 `#C9A227`、错误 `#FF5A5F`。
- **字幕**：无。可选右上角小字时间“23:47”，JetBrains Mono 14px，40% 不透明度。
- **声音**：机械键盘、SSH 连接成功提示音；音乐 pulse 进入。
- **转场**：硬切。

#### S03 · 报错蒙太奇（00:07–00:24）

**总原则**：每一次报错都必须完整出现“命令 → 报错 → 抖动 + 红框 + 音效 → 中文标签”四拍；节奏从 2.4 秒一次开始，最后一次在 2.6 秒内做三连抖。抖动幅度、红框不透明度、音效音高逐次升级，让观众感到“越来越糟”。

**节拍表**：

| # | 时间码 | 命令 | 画面报错 | 中文标签 | 抖动/红框 | 音效 |
| --- | --- | --- | --- | --- | --- | --- |
| E1 | 00:07.0–00:09.4 | `docker compose up -d` | `-bash: docker: command not found` | 环境没装 | 6px / 40% | 短 beep，880Hz |
| E2 | 00:09.4–00:11.8 | `docker ps` | `permission denied while trying to connect to the Docker daemon socket` | 权限不够 | 8px / 55% | 低频 buzz，110Hz |
| E3 | 00:11.8–00:14.2 | `docker compose up -d` | `Bind for 0.0.0.0:10999 failed: port is already allocated` | 端口被占 | 9px / 65% | 闷响 + beep |
| E4 | 00:14.2–00:16.6 | `docker compose config` | `yaml: line 18: did not find expected key` | 配置写错 | 10px / 75% | 数字 glitch |
| E5 | 00:16.6–00:19.0 | `./start_server.sh` | `-bash: ./start_server.sh: No such file or directory` | 脚本没了 | 11px / 85% | 双音错误提示 |
| E6 | 00:19.0–00:21.4 | `steamcmd +login anonymous` | `-bash: steamcmd: command not found`；切 `docker ps -a` 显示 `Restarting (1) 5 seconds ago` | 依赖缺失 / 无限重启 | 12px / 95% | 低音 horn |
| E7 | 00:21.4–00:24.0 | `docker compose logs -f` | 日志刷屏，master/caves 反复报错、重启；三连抖 | 无限重启 | 12px+ / 100% + 外发光 | 全部叠加 + reverse riser |

**每个错误的四拍节奏**（以 E1 为例）：

1. 0.0–0.4s：命令快速输入（打字速度 200%）。
2. 0.4–1.0s：报错输出，红色下划线从左到右扫过错误行。
3. 1.0–1.3s：画面抖动 + 红色边框脉冲 + 错误音 + 右上角计数从“0”跳到“失败 01”；之后每条错误递增一次。
4. 1.3–2.4s：停留，让观众读完错误；中文标签在左下角以 8 帧淡入。

**画面细节**：

- 红框：内缩 12px，颜色 `#E5484D`，1px 硬边 + 24px 外发光；E7 加到 20px 并让四角出现光晕。
- 抖动：位置关键帧，3 帧甩出、5 帧回位；旋转 ±0.3°；缩放 1.02；不开运动模糊。
- 故障：E4 与 E7 加 2–3px RGB 分离、3 条横向切片错位 12px，持续 2 帧。
- 失败计数：右上角 JetBrains Mono 20px，红色；每次跳动做 2 帧 scale punch；E7 显示“失败 07”并在下方加一条 1px 红线。
- 镜头：整体固定，E1–E6 每次报错时轻微推近 1–2%；E7 倾斜 0.3°，做“失控”感。

**字幕**：中文标签（左下，24px，白字红底 8% 衬底）+ 右上角失败计数。不让英文报错和中文标签同时占满画面。

**声音**：7 个错误音以 D–F–A 三个音为核心逐次升高，最后一个与 BGM 的 tape stop 重合；错误音不要刺耳，做低通和短混响，峰值控制在 -8 dBFS。

**转场**：E7 最后一帧硬切到定格。

#### S04 · 停顿（00:24–00:27）

- **镜头**：定格在 E7 画面，去饱和 40%，红框保留；缓慢推近到 102%；光标仍在闪。第 1.2s 第一行字出现，第 2.2s 第二行字出现；第 2.6s 红框开始向中心收缩。
- **素材**：V-ERR-07 定格帧 + 文字排版。
- **字幕**：
  - “折腾了半天，专服还是没开起来。”
  - “问题不在你。”（更小、更轻，放在第一行下方 16px）
- **声音**：所有声音在 00:24.0 切断，只留高频耳鸣、低频 drone、一次心跳；第 2.8s 一声轻键盘，作为转场触发器。
- **转场**：红框收缩，接 S05。

### 3.2 第二幕：转折与产品（00:27–00:34）

#### S05 · 转场（00:27–00:30）

这是全片唯一的“大转场”，需要提前在 AE 里做好 3 秒预合成。

1. **00:27.0–00:27.6**：黑底上只剩红框；红框高度压缩为 2px 横线（6 帧），颜色短暂去饱和。
2. **00:27.6–00:28.2**：横线断成四个 L 形角标，向四角飞散；角标速度曲线为 ease-out，带 2 帧运动模糊。
3. **00:28.2–00:29.0**：四个角标到达画面四角，变成应用窗口的四个圆角；边框颜色从红 `#E5484D` 经过灰 `#8A8578` 过渡到品牌绿 `#365443`；纸色 `#F4F2ED` 从窗口中心向外擦除。
4. **00:29.0–00:29.6**：荒字圆形标记以 trim path 画圆；wordmark 从下方 8px 滑入。
5. **00:29.6–00:30.0**：品牌语“把部署，变成点击。”淡入；镜头从 100% 拉到 96%，留出呼吸。

- **素材**：GFX-01 荒字标记、GFX-02 wordmark、GFX-03 边框/角标动画（AE 形状层）。
- **字幕**：荒野中枢 / DST 专服控制台 / 把部署，变成点击。
- **声音**：reverse riser 从 00:26.6 开始，00:27.0 impact，00:27.2 whoosh，00:29.2 轻铃；音乐 Cue 3 在 00:30.0 正拍进入。
- **转场**：动效转场结束后硬切到 S06。

## 4. 音频设计

### 4.1 音乐结构

| 段落 | 时间码 | BPM / 调性 | 配器与情绪 | 关键动作 |
| --- | --- | --- | --- | --- |
| Cue 1 紧张 | 00:00–00:27 | 100 BPM / D 小调 | 极简脉冲、时钟 tick、低频 drone、颗粒合成；克制但不安 | 00:02 进入；每次报错加一层打击；00:23.5 tape stop；00:24 静音 |
| Cue 2 转折 | 00:27–00:30 | 无固定拍 | riser、impact、whoosh、轻铃 | 00:27.0 impact；00:30.0 交给 Cue 3 |
| Cue 3 温暖 | 00:30–01:30 | 112 BPM / A 大调 | 毛毡钢琴、马林巴、软 kick、暖贝斯、拍手；明亮但不吵闹 | 00:34 鼓组进入；00:53 加 clap；01:02 抬升；01:20 抽简；01:26 终止和弦 |

**选曲关键词**（在 Artlist / Epidemic Sound / Musicbed / YouTube Audio Library 搜索）：

- `minimal tech tension pulse 100 bpm ticking`
- `warm minimal corporate marimba 112 bpm optimistic`
- `cinematic riser whoosh impact short`

不要选带明显人声的曲子；不要用强 EDM drop，产品片的气质是“松弛、可靠”，不是“燃”。

### 4.2 音效清单

| 时间码 | 音效 | 说明 |
| --- | --- | --- |
| 00:00 | 室内底噪 / 远处键盘 | 建立深夜氛围 |
| 00:04 | 键盘、SSH 连接提示 | 真实但轻 |
| 00:07–00:24 | 7 个错误音 | 同族不同音高；低通、短混响；峰值 -8 dBFS；全部原创合成，不采样系统错误音 |
| 00:21.4 | reverse riser | 与 E7 叠加，推向静音 |
| 00:24.0 | tape stop + 耳鸣 | 所有声音抽空 |
| 00:27.0 | impact + whoosh | 转场重音 |
| 00:29.2 | 品牌轻铃 | 不要卡通化 |
| 00:34–01:15 | 点击、输入、下拉、任务 tick、成功 | 每个交互只给一个轻反馈，避免嘈杂 |
| 01:20 | 终端关闭 / 吸附 | 轻、短 |
| 01:26 | 终止和弦 + 铃 | 留 2 秒尾音 |

### 4.3 混音

- 整体响度：-14 LUFS integrated，True Peak 不超过 -1 dBTP（B 站/YouTube 通用）。
- 有旁白时：BGM 降到 -18 LUFS 左右，侧链压缩 3–6 dB；旁白 -16 LUFS 左右。
- 错误音不要盖过音乐太多；用“短、干、低通”的方式做出痛感，而不是单纯拉高音量。
- 结尾留 1.5 秒淡出，不要硬切。

### 4.4 旁白（可选）

推荐先做**无旁白版**，靠字幕、音效和音乐叙事；如需旁白，用中性、克制的男声或女声，语速偏慢，不要广告腔。建议只读以下几句，留足画面呼吸：

> 为了开一个饥荒专服，你折腾了多久？
> 装环境、改配置、对着报错查半天。
> 其实，可以不用这样。
> 荒野中枢。连上你的 Linux 主机，确认指纹，检查环境，新建专服。
> 世界、MOD、备份，都在一个窗口里。
> 把折腾留给它，把游戏留给你们。

## 5. 画面与后期规范

### 5.1 轨道结构（Premiere / 剪映通用）


建议把“报错蒙太奇”“应用五步”“能力蒙太奇”分别做嵌套序列，方便整体调速和改字幕。

### 5.2 调色

- 终端段：压暗、冷色 5600K、红色饱和度 +10、轻微暗角；不要纯黑死黑，保留 3% 噪点。
- 应用段：暖色 5200K、纸色提亮、绿色保持准确；不要加青橙滤镜，产品 UI 的颜色要可信。
- 全片：3% 胶片颗粒、10–15% 暗角、极轻的色差；不要用重光效。

### 5.3 字幕

- 主字幕：思源黑体 Medium / Inter Medium，30px，1.2 倍行高，最多两行。
- 情绪标题：思源宋体 SemiBold，44–52px，字距 0.02em；只用在 S01、S04、S14。
- 标签/计数：JetBrains Mono 16–20px；失败计数用红色。
- 位置：底部 8%、左侧 6%；应用段加一条 90% 不透明的纸色衬底 + 1px 顶边，避免压在 UI 上。
- 关键词只高亮一个：痛点段用红，产品段用品牌绿。

### 5.4 动效参数

- 抖动：位移 6→12px，旋转 ±0.3°，缩放 1.02；3 帧出、5 帧回；不开运动模糊。
- 红框：内缩 12px，`#E5484D`，1px 硬边 + 24px 外发光；E7 加到 20px。
- 缩放推拉：100→125% 用于表单特写，ease-out 300ms；不要每镜都推，避免晕。
- 光标：28px 箭头 + 1px 白描边；点击加 48px 柔光圆环，180ms 扩散。
- 转场：全片 90% 硬切；唯一的大转场是 S05；S13 用 2 帧纸色微闪；S14 用叠化。
