# 添加主机认证输入修复验收

- 日期：2026-10-17
- 范围：添加表单密码/私钥路径/可选口令、原生文件选择命令、凭据导入与失败重试

## 行为

密码认证显示掩码输入框，缺少密码阻断提交。密钥认证显示本机私钥路径、选择文件按钮和可选口令；保存时 Rust 读取普通文件，限制 64 KiB 并检查 PEM/OpenSSH 格式，拒绝 .pub 公钥、目录、坏路径或超大文件。

元数据与凭据分别写入 SQLite 和系统凭据库，元数据请求不含秘密。凭据保存失败保留创建进度并沿用同一 serverId；关闭时不继续后续凭据保存，仍可从已创建记录补充。首次确认公钥保留本地预存凭据；认证仍在信任通过之后执行。

- Rust 常规测试 26 项通过，另有需要隔离 SSH 服务的集成用例默认跳过（本轮未重跑）。新增文件导入测试覆盖公钥/目录/超大文件拒绝、内容转换后不序列化路径。扩展生产凭据工作流测试验证未信任时可本地保存、登录仍拒绝、首次确认后内容保留。
