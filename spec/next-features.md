# 后续功能

- 版本：1.0.5（Bate）
- 依据：当前生产代码与 [当前状态](../docs/current-status.md)

## 已规划、待实现

以下能力已有设计文档，但代码尚未实现；未实现前不注册 command，界面不提供可点击的假入口。

- **DST 实例更新**：检查新 build、固定目标 Release、冷保护备份、切换活动发布、验证与回滚。见 [DST 更新设计](dst-update-plan.md)。
- **定时备份与保留策略**：远端 timer 按实例执行准热备份，桌面关闭和主机重启后仍生效；只自动清理定时来源。见 [定时备份设计](scheduled-backup-plan.md)。
- **玩家信息列表与踢出**：通过自带服务端桥接 MOD 读取在线玩家名称、角色和分片，并支持踢出。见 [玩家列表设计](player-list-plan.md)。

总体优先级、难度、依赖和验收顺序见 [运维增强规划](ops-enhancements-plan.md)。

## 真实环境验证

- Linux amd64 目标主机的 Docker/Compose 兼容矩阵。
- Master/Caves 双分片、三实例隔离和同实例更新。
- 公网大厅、LAN、Steam 查询和玩家连接。
- 主机重启、Docker 重启、SSH 断线后的任务对账。
- 备份恢复、MOD 缺失和世界配置回滚的真实故障场景。
